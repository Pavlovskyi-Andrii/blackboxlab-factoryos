FactoryOS Local Render Booster v1\n\nUses a Windows PC as optional Media Finisher compute without exposing the PC to the internet.\n\nFactoryOS stays the control plane and durable artifact store. The PC sends outbound HTTPS heartbeats, claims Local jobs, runs the same media_finisher_worker Docker image, and uploads final.mp4 plus short clips back to FactoryOS. QA and HUMAN APPROVAL remain mandatory.\n\nNo port forwarding, public IP, inbound tunnel, or automatic publishing is required.\n\nWindows requirements: Docker Desktop and Python 3.\n\nRun from repository root:\npowershell -ExecutionPolicy Bypass -File .\\local_booster\\START_LOCAL_BOOSTER.ps1\n\nV1 uses CPU for broad compatibility. CUDA acceleration can be added after the pull-worker path is verified.\n
