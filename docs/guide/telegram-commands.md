# Руководство по командам Telegram-бота FactoryOS Relay

Справочное руководство для владельца по всем командам Telegram-бота FactoryOS Relay.

## Список команд

### /start
- **Что делает:** Запускает бота и выводит начальное приветствие со справкой.
- **Пример:** `/start`

### /help
- **Что делает:** Показывает полную справку по всем командам бота.
- **Пример:** `/help`

### /pair
- **Что делает:** Привязывает этот Telegram-чат к FactoryOS по одноразовому коду. Код показывает FactoryOS при запуске сопряжения; без кода команда ничего не делает. Так же работает `/start КОД`.
- **Пример:** `/pair 123456` (вместо 123456 — ваш код)

### /status
- **Что делает:** Показывает текущий статус работы бота, состояние очереди задач и воркеров.
- **Пример:** `/status`

### /tasks
- **Что делает:** Выводит список всех активных задач (в очереди, в работе, требующих внимания).
- **Пример:** `/tasks`

### /relay
- **Что делает:** Выводит общий обзор системы Relay и активных задач.
- **Пример:** `/relay`

### /roadmap
- **Что делает:** Показывает текущую дорожную карту (Roadmap) и задачи.
- **Пример:** `/roadmap`

### /task
- **Что делает:** Открывает карточку задачи по её идентификатору (ID).
- **Пример:** `/task R-0001`

### /history
- **Что делает:** Показывает историю событий, изменений статусов и действий в Relay и GitHub.
- **Пример:** `/history`

### /github
- **Что делает:** Отображает статус репозитория GitHub, открытых PR и результаты проверок CI.
- **Пример:** `/github`

### /issue
- **Что делает:** Ставит открытый GitHub Issue в очередь исполнения воркера.
- **Пример:** `/issue 41`

### /battles
- **Что делает:** Показывает список и статус тестовых прогонов (Battle Runs).
- **Пример:** `/battles`

### /battle
- **Что делает:** Просмотр подробной информации по конкретному Battle Run.
- **Пример:** `/battle battle_3f9c2a1b7d4e5f60` (ID берите из списка `/battles`)

### /workers
- **Что делает:** Отображает статус и состояние воркеров (Claude, ChatGPT, Gemini) и операторов.
- **Пример:** `/workers`

### /operators
- **Что делает:** Показывает состояние и статус доступных линий операторов.
- **Пример:** `/operators`

### /new
- **Что делает:** Создаёт новую задачу в Relay и отправляет её в очередь воркеру.
- **Пример:** `/new Исправить ошибку при загрузке данных`

### /work
- **Что делает:** Переводит задачу в статус «В работе» (in progress).
- **Пример:** `/work R-0001`

### /done
- **Что делает:** Завершает задачу и переводит её в статус «Готово» (done).
- **Пример:** `/done R-0001`

### /need
- **Что делает:** Помечает задачу как требующую внимания владельца (need_you).
- **Пример:** `/need R-0001`

### /inbox
- **Что делает:** Возвращает задачу обратно в исходный статус «Inbox».
- **Пример:** `/inbox R-0001`
