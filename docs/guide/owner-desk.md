# «Ваши задачи»: стол владельца

Здесь собраны дела, которые может сделать только владелец. Агенты их не берут и не обходят.

## Что это

- Блок «Ваши задачи» — список пошаговых инструкций (runbook) для задач с пометкой `[HUMAN]` из `ROADMAP.md`.
- Сейчас в нём 21 инструкция: например, T-506 (привязать Telegram-бота), T-605 (ключ Gemini в Render), T-521 (первый реальный пост с вашим одобрением), T-645-H (утвердить демо-выпуски MyCast).
- Тест в CI следит, чтобы у каждой открытой `[HUMAN]`-задачи в `ROADMAP.md` была инструкция.

## Что внутри карточки

- Номер и название задачи, статус и короткая строка факта.
- Короткое объяснение, зачем это нужно, и примерное время («Время»).
- Шаги. В каждом шаге: что сделать, «Как проверить», «Если что-то пошло не так» (готовые ответы на известные ошибки).
- «Готово, когда» — по какому признаку задача считается сделанной.

## Статусы

| Статус | Что значит |
|---|---|
| «Сделать» | задача ждёт вас |
| «Проверить» | нужно сверить факт, например версию на проде |
| «Ждёт» | сначала нужна другая задача (например, T-592-H ждёт T-591-H) |
| «Необязательно» | можно не делать |
| «Готово» | сервер видит, что всё сделано |
| «Неизвестно» | у сервера нет данных для проверки |

Строка факта берётся из того, что сервер уже знает. Примеры: `gemini_key_ok` — «Ключ Gemini есть в Render», `gemini_key_missing` — ключа ещё нет; `tg_paired` — Telegram привязан; для T-591-H — вердикт `/proof` по последнему тикету из Telegram. Сервер при этом не вызывает внешних провайдеров.

## Как выполнить задачу

1. Откройте карточку со статусом «Сделать» (первая такая карточка раскрыта сама).
2. Пройдите шаги по порядку во внешнем сервисе: Render, Telegram, Google AI Studio, GitHub и т. д.
3. После каждого шага проверьте результат по строке «Как проверить».
4. Статус меняется сам, когда сервер увидит факт. Например, T-605 станет «Готово», когда после деплоя в Render сервер увидит `FACTORY_GEMINI_API_KEY`.
5. Кнопки «отметить выполненным» нет: статус нельзя поставить вручную.

## Если непонятно

- Выделите текст в шаге или нажмите «Спросить про этот шаг», затем «Отправить».
- Вопрос забирает воркер Claude на EC2 и отвечает между своими задачами, только читая репозиторий: обычно за несколько минут, иногда до часа.
- Ответ появится под карточкой, а Telegram пришлёт уведомление.
- Не вставляйте токены и пароли: похожий на секрет текст сервер заменяет на «[скрыто]». Одновременно может ждать не больше 20 вопросов.

## Почему агенты не делают это сами

По правилам проекта (`CLAUDE.md`) агент останавливается и передаёт дело владельцу, когда нужны:

- секрет или ключ, которого ещё нет (ключ вставляется только в Render, AWS или терминал);
- оплата или подтверждение платного провайдера;
- доступ к внешнему аккаунту (Google, YouTube, GitHub, Telegram);
- явное одобрение реальной публикации;
- необратимое продуктовое или бизнес-решение.

Агентам также запрещено менять переменные окружения на проде и включать платные вызовы.

## Где найти

- Главная панель → в меню «Воркеры» → окно «Воркеры / Центр делегирования» → блок «Ваши задачи» в самом верху.
- Блок видит только владелец. Те же `[HUMAN]`-задачи есть на странице «Задачи команды» в плитке владельца.

## Ограничения

- Живую проверку имеют не все карточки: у части статус постоянный («Сделать», «Необязательно») или «Неизвестно».
- Текст инструкций статичный: его меняют агенты через обычный PR.
- Отметка `[x]` в `ROADMAP.md` ставится отдельно, коммитом в репозиторий, а не из этого блока.
