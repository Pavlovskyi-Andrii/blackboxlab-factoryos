# Google Calendar для MyCast — настройка владельцем (доступ только на чтение)

Цель: слушатель нажимает «Подключить Google Календарь» на странице MyCast, даёт доступ **только на чтение**, и в конце
выпуска звучат сегодняшние встречи и дни рождения друзей. В календарь ничего не записывается.

Состояние кода: кнопка подключения и OAuth-процесс делаются только после выполнения шагов 1–6 (им нужен секрет клиента).
До этого страница честно показывает «не подключено».

## Ограничения, которые нужно знать заранее (исправлено после ревью Codex в #332)
- **Статус публикации и верификация — это разные вещи.** Статус (*Testing* / *In production*) задаётся
  в разделе Audience; верификация — это проверка приложения со стороны Google.
- *Testing*: подключиться могут только добавленные вами тестовые пользователи (не больше 100), и **их доступ к календарю истекает каждые 7 дней**
  (Google выдаёт 7-дневные refresh-токены приложениям в режиме Testing, которые запрашивают чувствительные права). Еженедельное переподключение —
  это ожидаемое поведение, а не ошибка.
- *In production* без верификации: попробовать может любой, но он увидит предупреждение «непроверенное приложение», а Google ограничивает
  число пользователей, которые могут выдать непроверенному приложению чувствительное право.
- *In production* с верификацией: без предупреждения и без еженедельного истечения доступа.
- **Статус действует на весь проект.** Если проект, в котором настроен вход в MyCast через Google, уже
  *In production*, **не** переключайте его в *Testing*: все, кого нет в тестовом списке, потеряют вход через Google.
- Для верификации нужен **собственный домен**: MyCast использует **mycast.pro** (куплен 2026-11-13).

## Шаги
1. **Проект** — https://console.cloud.google.com → выберите проект, в котором настроен вход в MyCast через Google
  (клиент, стоящий за `FACTORY_GOOGLE_CLIENT_ID`).
2. **Включите API** — ☰ → APIs & Services → Library → "Google Calendar API" → Enable.
3. **Право только на чтение** — ☰ → Google Auth Platform → Data Access → Add or remove scopes →
  `https://www.googleapis.com/auth/calendar.readonly` → Update → Save.
  Этого хватает и для встреч, и для календаря Google «Дни рождения» (Birthdays).
4. **Redirect URI** — Google Auth Platform → Clients → клиент типа *Web application* → Authorized redirect URIs →
  добавьте `https://mycast.pro/api/mycast/calendar/callback` (и для старого адреса
  `https://blackboxlab-factoryos.onrender.com/api/mycast/calendar/callback`). В **Authorized JavaScript origins**
  добавьте `https://mycast.pro` (вход через Google на новом домене). Сохраните.
5. **Секрет клиента в Render** — в том же клиенте скопируйте *Client secret* (или нажмите *Add secret*) → Render → сервис
  `blackboxlab-factoryos` → Environment → `FACTORY_GOOGLE_CLIENT_SECRET` → Save. Никогда не вставляйте его в чат или в Git.
6. **Тестовые пользователи** — Google Auth Platform → Audience. Только если статус уже *Testing*: Test users → добавьте до
  100 адресов Gmail. Если статус *In production*, ничего не меняйте (см. ограничения выше).
7. **Брендинг** — Google Auth Platform → Branding: название приложения (MyCast), email поддержки, домашняя страница `https://mycast.pro`,
  политика конфиденциальности `https://mycast.pro/privacy`, условия использования `https://mycast.pro/terms`, разрешённый домен `mycast.pro`.
8. **Верификация (с собственным доменом)** — подтвердите домен в Google Search Console, затем Google Auth Platform →
  Verification Center → отправьте заявку: короткое видео, где видно экран согласия и то, как используются данные календаря, и
  обоснование для `calendar.readonly`. Опишите реальный путь данных (ревью Codex в #333): «MyCast читает только сегодняшние события
  и календарь Birthdays в момент подготовки выпуска для слушателя. Названия и время событий передаются в Anthropic
  Claude (пишет сценарий выпуска) и Google Gemini (озвучивает его); аудио отправляется в личный Telegram-чат
  слушателя. MyCast не хранит данные календаря, не использует их ни для чего другого и не продаёт и не передаёт их
  никому другому». Это совпадает с https://mycast.pro/privacy.

Когда шаги 1–6 выполнены, напишите Claude «готово»: следующим этапом будут сделаны кнопка подключения, OAuth-процесс и блок календаря в выпуске.
