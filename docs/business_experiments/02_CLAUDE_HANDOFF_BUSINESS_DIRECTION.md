**Дата:** 2026-11-01

**Сопутствующий документ:** [01_PRODUCT_HYPOTHESES.md](01_PRODUCT_HYPOTHESES.md).

## Прочитай прежде всего

Владелец обсуждал с ChatGPT запасные направления для FactoryOS/Blackbox Lab. Изначальная идея AI-видеофабрики может не найти платежеспособный рынок. Владелец хочет иметь варианты, но **пока не выбрал второй рынок, не утвердил fork, не разрешал разработку нового продукта или рекламную кампанию**.

Гипотезы (обсуждение, не план работ):

1. **AI Media Factory** — производство видео для авторов и бизнеса.
2. **AI Team for Business** — AI-исполнители для повторяющихся операций малого бизнеса.
3. **Startup Validation Lab** — валидация идеи через оффер, демо/лендинг, согласованный контакт с аудиторией и измерение спроса.
4. **AI Engineering Team** — координация специализированных AI-разработчиков на проверяемом инженерном процессе.

Потенциальный общий фундамент: существующие агенты, Relay, Worker Center, Agent Office, trace/status, human approval и CI. Сначала доказательства спроса, потом решение о специализации, ответвлении или масштабировании.

## Что точно подтверждено владельцем

- Владелец определяет **что строить, зачем и в каком приоритете**; напрямую ставит задачи Claude и ChatGPT.
- Claude координирует текущую техническую разработку FactoryOS по действующему ROADMAP; ChatGPT может брать отдельные независимые второстепенные задачи **только с подтверждённым ownership и без конфликта**.
- В будущем задача/ответ между агентами должна передаваться в **FactoryOS Relay**, а не через комментарии GitHub как рабочий транспорт. GitHub остаётся для репозитория, PR, CI и документации.
- При лимите Claude желателен безопасный checkpoint и передача независимых задач; hourly ChatGPT inbox — задуманный механизм, **не доказанная сейчас работающая автоматизация**.
- Платные API/облака/реклама, обращения к потенциальным клиентам, рассылки и публичные публикации — только после отдельного подтверждения владельца.

## Что НЕ утверждено

- Не принято решение делать fork или вести два действующих продукта.
- Не утверждён новый роадмап или автоматическое создание задач по этим гипотезам.
- Не принято решение отдать Claude все продуктовые решения: вопрос об эффективности AI-постановки технических задач был именно вопросом владельца.
- Нет разрешения запускать лендинги, закупать рекламу, писать клиентам или выставлять реальные счета.
- Нельзя считать GitHub-комментарий доказательством, что Claude Worker увидел сообщение или начал работу.

## Как действовать Claude

**Сейчас:** прочитай оба документа, сохраняй этот контекст при обсуждениях с владельцем. Можешь предложить узкие проверки гипотез, но **не запускай их без отдельной команды**. Не добавляй новые обязательные задачи в ROADMAP по содержимому этого файла. При необходимости укажи владельцу, какие метрики нужны для выбора.

**В текущей технической разработке:** продолжай действующий ROADMAP и проверку Depends/Owner; не отвлекайся на новую идею без согласования. Если передаёшь ChatGPT независимую задачу, сверяй активные claims и файлы, не назначай её обоим агентам.

**Чтение и координация:** отдельные подтверждённые рабочие правила оформлены в `docs/handoff/CLAUDE_CHATGPT_COORDINATION.md` (PR #95, может быть ещё не в main). Будущий Relay bridge описан в Issue #94. Документы здесь — бизнес-контекст, а не замена техпротокола.
